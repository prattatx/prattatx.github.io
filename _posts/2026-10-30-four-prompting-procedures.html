Andrej Karpathy shared four prompts that change the shape of the answer you get from a language model. Below, each one is a short procedure with the prompt itself and a working example of what it produces. The text follows ASD-STE100 at about 80%, which is what the first procedure tells you to do.

Always check the output before you use it. The model does the legwork. You are responsible for the result.

Figure 1. Select the output type. The human tasks are at the top and the bottom. The model does the work between them.

Explain it in ASD-STE100

ASD-STE100 is Simplified Technical English. It is a controlled language for aerospace maintenance documents. Language models know its rules well. Text that follows the rules is easy to read.

Caution: do not ask for 100% compliance. Full compliance makes the text sound robotic. Ask for about 80%.

  1. Write the topic that you want explained.
  2. Tell the model to use ASD-STE100.
  3. Tell the model to follow the rules about 80% of the time.
  4. Read the answer. If a sentence is unclear, ask for that sentence again.
PromptExplain [topic] in ASD-STE100. Follow the rules about 80% so it still sounds natural.

The same explanation at four compliance levels

The main rules

RuleWhat it says
LengthProcedure sentences: 20 words maximum. Descriptive sentences: 25 words maximum.
One stepWrite one instruction in each sentence. Use the imperative: "Remove the cover."
VoiceUse the active voice. Say who or what does the action.
WordsUse approved words. Give each word one meaning only.
OrderPut warnings and cautions before the step they apply to.
ParagraphKeep a paragraph to one topic and six sentences or fewer.

Ask for a diagram

Clear text still has to be read, one line at a time. A diagram shows the full structure at one time. The reader can process it faster.

  1. Write the topic.
  2. Tell the model to make a diagram, not a paragraph.
  3. Make sure that each box and each arrow has a label.
  4. If the diagram has too many parts, ask for a smaller diagram for each part.
PromptInstead of writing this out, create a diagram that explains [topic].

Here is the same information both ways. As text: each month, you add the same amount of money to the account. At the end of each month, the account earns interest on the full balance. The interest becomes part of the balance. The next month, the account earns interest on the money that you added and on the old interest. This is compounding.

Ask for the output in HTML

Language models are very good at front-end code. When you ask for HTML, you get a page that you can use, not only read. The video that relayed Karpathy's post used a SIP calculator as the example. A SIP is a fixed investment that you make each month.

  1. Write what the page must do.
  2. Name the inputs that the reader must change, for example sliders.
  3. Name the result that the page must show, for example a chart for each year.
  4. Open the page and move each input. Make sure that the result changes correctly.
PromptMake the output in HTML. Build a SIP calculator that shows compounding year by year, with sliders and animations.

Ask for an explainer video

This is the format that Karpathy is most bullish on: a custom explainer video on any topic. The video below was made with this prompt, and its topic is these four procedures. Narration needs a text-to-speech key, such as one from ElevenLabs. Keep the key in a local file, not in the chat.

  1. Write the topic.
  2. Ask for a 3Blue1Brown style video: dark background, shapes that move, few words on screen.
  3. Tell the model where your ElevenLabs key is.
  4. Watch the full video. Make sure that the narration and the animation agree.
PromptCreate a 3Blue1Brown style video explainer on [topic]. Use my ElevenLabs API key for audio narration.

The bigger point

Language models will do more of the legwork. Human work moves up into oversight. Intelligence and code are now cheap, so Karpathy suggests that you ask for large, custom, throwaway software that did not make sense to build before.

Push the limits. Then check what comes back.
